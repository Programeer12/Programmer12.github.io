About Me

>_ id: student

I'm a cybersecurity student with a hands-on interest in offensive security. My path started with web development — building things in PHP, MySQL, and Flutter — which gave me an insider's view of how applications are put together. That turned into a curiosity about where those assumptions break.

Right now I'm deep into web application security, network fundamentals, and Linux tooling. You'll usually find me running enumeration scripts, reading through Burp Suite write-ups, or breaking my own Flutter apps to see how the mobile side behaves.

I care about clean, documented work — whether that's a penetration testing report, a PHP endpoint that doesn't allow SQL injection, or a Flutter UI that handles its state properly.

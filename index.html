    Questions I get asked
    
        
    

        
    
          
    
            
            
            
            
          
    
          
        
    

        
    
          
    
            What is the OWASP Top 10, and why does it matter?
            
    
              It's a regularly updated list of the most critical web application security risks, such as broken access
              control, injection, and security misconfiguration. I use it as a checklist when I review my own PHP and
              Flutter back ends, because it turns "make it secure" into specific things I can test.
            
    
          
    

          
    
            How do you prevent SQL injection in PHP?
            
    
              I never build queries by joining strings with user input. I use prepared statements with bound parameters
              (PDO or mysqli), validate input on the server, and give the database account only the permissions the
              app needs.
            
    
          
    

          
    
            What does your testing workflow look like?
            
    
              Recon first (what is exposed?), then enumeration, then analysis of what the results mean, and only then
              testing. I only test targets I own or have permission to test: my own apps, CTF platforms, and practice
              labs. Every test ends in a written report with a fix for each finding.
            
    
          
    

          
    
            Why Flutter for mobile apps?
            
    
              One Dart codebase can target Android and iOS, hot reload keeps UI iteration fast, and the widget model makes
              state handling explicit, which also makes it easier to see where data could leak or go wrong.
            
    
          
    

          
    
            How do you keep a PHP and MySQL project safe?
            
    
              Database access lives in one place, every query is parameterised, passwords are hashed with
              password_hash(), and config values stay outside the web root. I treat every request as
              untrusted until the server has checked it.
            
    
          
    

          
    
            What are you looking for right now?
            
    
              Internships and freelance projects in application security, penetration testing, or secure development,
              plus CTF teams to learn alongside. The contact form below is the quickest way to reach me.
            
    
          
    

          
    
            How do you keep learning?
            
    
              Daily practice: write-ups, labs, CTFs, and rebuilding my own apps to see where they break. I note what each
              finding taught me so it becomes a habit in the next project.
